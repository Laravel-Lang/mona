| Package | Provides | Compatibility |
| --- | --- | --- |
| [forxer/generic-term-translations-for-laravel](https://github.com/forxer/generic-term-translations-for-laravel) | Translations for generic terms | [Legacy Publisher](https://github.com/forxer/generic-term-translations-for-laravel/blob/main/composer.json) |

For Mona 20.x, check that a release of the plugin supports Publisher 20.x and includes a `laravel_lang.json` manifest. The version linked above uses the legacy Publisher. Plugin authors can follow the [plugin migration guide](./upgrade.md#replace-legacy-plugin-registration) and [test the updated pack](./plugins.md#test-a-pack-in-a-laravel-application) before publishing it.
