---
title: Available locales
description: Look up the canonical locale codes supported by Laravel-Lang Mona.
---

Use the codes below with [Artisan](./translations.md) and in Laravel's locale settings. For example, run `php artisan lang:add pt_BR` to install Brazilian Portuguese. A [configured alias](./configure.md#locale-aliases) can be accepted as input, while generated files use the canonical code.

Find the list in code with [`Locale::values()`](./locales.md#find-supported-and-installed-locales). Translation coverage varies by pack and locale.
