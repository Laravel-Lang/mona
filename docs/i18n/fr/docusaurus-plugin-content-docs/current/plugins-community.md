Vérifiez les dépendances Composer du plugin avant de l’installer. Les auteurs de plugins peuvent suivre le [guide de migration des plugins](./upgrade.md#replace-legacy-plugin-registration) pour passer de l’enregistrement par fournisseur de services à la détection des manifestes.

Avant l’installation, vérifiez qu’une version prend en charge Publisher 20.x et inclut un manifeste `laravel_lang.json`. [Tester le paquet mis à jour](./plugins.md#test-a-pack-in-a-laravel-application)
