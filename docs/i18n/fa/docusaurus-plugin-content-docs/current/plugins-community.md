پیش از نصب افزونه، الزامات Composer آن را بررسی کنید. نویسندگان افزونه می‌توانند طبق [راهنمای مهاجرت افزونه](./upgrade.md#replace-legacy-plugin-registration) از ثبت با ارائه‌دهندهٔ سرویس به شناسایی از طریق فایل مانیفست مهاجرت کنند.

قبل از نصب، بررسی کنید که نسخهٔ بسته با Publisher 20.x سازگار باشد و پروندهٔ `laravel_lang.json` را داشته باشد. [آزمایش بستهٔ به‌روزشده](./plugins.md#test-a-pack-in-a-laravel-application)
