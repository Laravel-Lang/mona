---
title: Управление переводами
description: Добавляйте, обновляйте и удаляйте переводы приложения и пакетов с помощью Publisher в Mona.
---

Publisher входит в официальные пакеты переводов. Его команды Artisan записывают переводы PHP и JSON в языковой каталог приложения, обычно `lang/`. Файлы для отдельных пакетов могут появляться также в `lang/vendor/`.

Выполняйте команды Artisan из корневого каталога приложения. Каталог переводов определяет `lang_path()`.

## Добавление локалей {#add-locales}

Передайте один или несколько [кодов локалей](./available-locales.md) через пробел. Команда принимает настроенные алиасы, а в созданных файлах использует канонические коды.

```bash
php artisan lang:add fr de_CH
```

Команда создаёт каталоги локалей и обновляет **все установленные локали**, включая текущую и резервную локали приложения. Без аргументов она спрашивает, нужно ли установить все поддерживаемые локали. В скриптах передавайте коды явно.

Если среди аргументов есть неизвестный код, команда завершится с ошибкой до создания каталогов.

## Обновление переводов {#update-translations}

```bash
php artisan lang:update
```

Команда `lang:update` обновляет все установленные локали и не принимает коды локалей в качестве аргументов.

Publisher определяет локали по текущей и резервной локалям приложения, файлам и каталогам непосредственно в языковом каталоге и по JSON-файлам в `lang/vendor/<package>/`. Наличие только каталога PHP-переводов пакета не делает локаль установленной. Выполните `lang:add` для этой локали, чтобы создать её каталог в приложении.

В [манифестах плагинов](./plugins.md) пакеты переводов объявляют поддерживаемые пакеты, версии и файлы назначения. Publisher объединяет общие словари со словарями пакета и добавляет полученные переводы в каждый файл назначения. Он сохраняет сторонние ключи и заменяет значения совпадающих ключей, в том числе числовых. Если фразы нет в словарях, Publisher записывает исходную фразу. Храните собственные переопределения в отдельных файлах переводов или [исключите](./configure.md#skip-files-and-force-integrations) генерируемые файлы, которые ведёте самостоятельно.

Выполняйте `lang:update` после изменения зависимостей Composer или [настроек публикации](./configure.md). Просмотрите полученные изменения.

В свежей копии проекта до публикации переводов выполните `composer install`. Развёртывайте сгенерированные файлы вместе с приложением или создавайте их при развёртывании, если каталог переводов доступен на запись. Если файлов ещё нет, выполните `php artisan lang:add fr de_CH --no-interaction` с нужными кодами. Чтобы обновить существующие файлы, выполните `php artisan lang:update --no-interaction`.

## Удаление локалей {#remove-locales}

```bash
php artisan lang:rm de_CH
```

Передавайте канонические коды или настроенные алиасы.

Команда удаляет каталог и файл JSON с каноническим кодом локали непосредственно из языкового каталога и из каждого каталога `lang/vendor/<package>/`, включая находящиеся там пользовательские файлы. Текущая и резервная локали защищены. Без аргументов команда спрашивает, удалить ли все незащищённые локали. Ответ по умолчанию — «нет». Если каталог локали является ссылкой, команда удаляет саму ссылку.

Для каждой локали команда показывает `DONE`, `PROTECTED`, `INVALID`, `SKIP` или `FAILED`. Если после попытки удаления остался файл или каталог, команда выводит его путь и возвращает код ошибки. Проверяйте статус каждой локали, поскольку `PROTECTED`, `INVALID` и `SKIP` возможны при успешном завершении.

## Поиск команд Artisan {#find-the-artisan-commands}

Выполните `php artisan help lang:add`, чтобы проверить регистрацию команды. Если команды нет, проверьте установку пакета через `composer show laravel-lang/publisher` и выполните `php artisan package:discover`. Если автоматическое обнаружение Config и Publisher отключено, зарегистрируйте `LaravelLang\Config\LangConfigServiceProvider::class` и `LaravelLang\Publisher\LangPublisherServiceProvider::class` в `bootstrap/providers.php`.

## Резервный поиск в JSON {#json-fallback}

Если ключа нет в JSON-переводе, `laravel-lang/json-fallback` добавляет поиск в JSON-файле резервной локали перед переходом к PHP-переводам. Пакет входит в Common. Для отдельной установки выполните `composer require laravel-lang/json-fallback`.

Добавьте `LaravelLang\JsonFallback\LangJsonFallbackServiceProvider::class` в список сервис-провайдеров приложения в `bootstrap/providers.php`. Если в этом списке явно указан `Illuminate\Translation\TranslationServiceProvider`, замените его сервис-провайдером Mona. [Регистрация сервис-провайдеров в Laravel](https://laravel.com/docs/13.x/providers#registering-providers)

Если текущая локаль — французская, а резервная — английская, ключ, отсутствующий в `lang/fr.json`, теперь может получить значение из `lang/en.json`.

Чтобы ограничить поиск запрошенной локалью, вызовите `Lang::get($key, fallback: false)` через фасад `Illuminate\Support\Facades\Lang`.
