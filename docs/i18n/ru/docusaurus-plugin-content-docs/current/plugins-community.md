Перед установкой плагина проверьте его требования в Composer. Авторы плагинов могут перейти с регистрации через сервис-провайдер на обнаружение манифестов по [руководству по миграции плагинов](./upgrade.md#replace-legacy-plugin-registration).

Перед установкой проверьте, что версия плагина поддерживает Publisher 20.x и содержит манифест `laravel_lang.json`. [Проверка обновлённого пакета](./plugins.md#test-a-pack-in-a-laravel-application)
