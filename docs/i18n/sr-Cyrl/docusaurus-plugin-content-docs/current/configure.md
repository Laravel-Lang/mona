Mona аутоматски учитава подразумевана подешавања. Објавите датотеке које желите да прилагодите у директоријуму `config/` апликације.

```bash
php artisan vendor:publish --tag=localization_main
```

Ознака `localization` објављује свих пет датотека. Назив сваке датотеке без наставка `.php` служи и као ознака за објављивање и као кључ подешавања у Laravel-у.

| Датотека | Подешавања |
| --- | --- |
| `localization_main.php` | Стилови превода, алијаси и филтери објављивања |
| `localization_punctuation.php` | Паметна интерпункција и наводници за појединачне локале |
| `localization_routes.php` | [Називи рута, извори локала и мидлвер](./routes.md) |
| `localization_models.php` | [Суфикс модела превода, филтрирање и путање генератора](./models.md) |
| `localization_map.php` | Метаподаци локала, попут писма, региона и смера писања |

Laravel замењује свако подешавање највишег нивоа вредношћу из апликације. Када мењате низ `locales` у `localization_punctuation.php`, задржите подразумевана подешавања за локале која још желите да користите.

После измене подешавања обришите постојећи кеш конфигурације командом `php artisan config:clear`. Покрените `php artisan lang:update` да поново генеришете преводе на које утичу подешавања објављивања.

## Стилови превода {#translation-styles}

Стил превода је именовани речник који мења формулацију одабраних израза. Пакет може, на пример, да садржи `informal.json` за неформалан тон или `john.json` за формулације које користи одређени производ. Називи стилова независни су од кодова локала и назива апликација или пакета. Сваки пакет превода може да понуди стил у `locales/<locale>/<style>.json` за језике које покрива. Стил може да садржи и само један израз. Првобитно се користио за неформално обраћање. [Дискусија о неформалним преводима](https://github.com/orgs/Laravel-Lang/discussions/124)

Када инсталирате додатак који обезбеђује `john`, наведите га као последњи у `config/localization_main.php` да добије предност у сваком извору речника.

```php
'styles' => ['default', 'informal', 'john'],
```

Када покренете `php artisan lang:update`, Publisher спаја датотеке стилова за сваки инсталирани локал. За сваки израз предност има `john` ако га садржи, затим `informal`, па `default`. На пример, француски пакет може да замени један израз у `locales/fr/john.json`, док се за исти израз на немачком користи `locales/de/informal.json` или `locales/de/default.json`. Publisher засебно примењује овај редослед на заједнички Library и на пакет који обезбеђује датотеку. За ту датотеку одговарајући израз из пакета има предност над уносом из Library-а.

Подразумевано подешавање је `['default', 'inline']`. Стил `inline` обезбеђује опште поруке валидације, попут „Ово поље мора бити прихваћено“. Подесите `styles` на `['default']` да користите само стандардне формулације. Ако изоставите `default` са списка, Publisher га додаје на почетак.

## Алијаси локала {#locale-aliases}

Подесите `localization_main.aliases` као мапу канонских кодова у алијасе. На пример, додајте следећи унос у низ који враћа `config/localization_main.php`.

```php
'aliases' => [
    'de_CH' => 'de-CH',
],
```

Artisan може да прихвати `de-CH`, док Laravel и објављене датотеке користе `de_CH`. За `APP_LOCALE` и `APP_FALLBACK_LOCALE` наведите канонске кодове. Примере претварања и претраге потражите у [Локалима и називима](./locales.md).

При поређењу алијаса разликују се мала и велика слова. За сваки локал изаберите јединствен алијас који се разликује од канонских кодова других локала.

## Изузимање датотека и принудно укључивање интеграција {#skip-files-and-force-integrations}

- `localization_main.skip` упоређује обрасце са `*` са пуним путањама чији је раздвајач `/`, без разликовања великих и малих слова. Тако можете изузети изворне датотеке, речнике и одредишта објављивања. На пример, `['*/lang/fr/validation.php']` спречава Publisher да упише ту датотеку у апликацији која користи `lang/`.
- `localization_main.force` прихвата називе Composer пакета. Омогућава Publisher-у да користи уносе из манифеста чак и када наведена зависност недостаје, инсталирана верзија се не подудара или се назив коренског пројекта разликује. Користите ово подешавање када су преводи из манифеста применљиви на вашу апликацију.

`skip` има предност над `force`.

## Паметна интерпункција {#smart-punctuation}

Подесите `LOCALIZATION_PUNCTUATION_ENABLED=true` да укључите типографске наводнике, црте и тротачку у објављеним преводима. Уредите `localization_punctuation.common` за општа правила и `localization_punctuation.locales` за посебна правила по канонском коду локала. Правила се примењују када Publisher следећи пут упише преводе.

## Метаподаци локала {#locale-metadata}

`localization_map.locales` повезује канонске кодове са писмом (`type`), регионалним локалом (`regional`) и опционим смером писања (`direction`). Користите `Direction::LeftToRight` ако смер није подешен.

```php
use LaravelLang\LocaleList\Direction;

$metadata = config('localization_map.locales.ar', []);
$script = $metadata['type'];         // 'Arab'
$regional = $metadata['regional'];  // 'ar_AE'
$dir = ($metadata['direction'] ?? Direction::LeftToRight)->value; // 'rtl'
```
