O‘rnatishdan oldin Publisher 20.x ga mos va `laravel_lang.json` manifestini o‘z ichiga olgan reliz borligini tekshiring. [Yangilangan paketni sinash](./plugins.md#test-a-pack-in-a-laravel-application)
