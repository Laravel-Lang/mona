---
title: "Mavjud lokallar"
description: "Laravel-Lang Mona qo‘llab-quvvatlaydigan kanonik lokal kodlarini toping."
---

Quyidagi kodlardan [Artisan](./translations.md) buyruqlarida va Laravel’ning lokal sozlamalarida foydalaning. Masalan, Braziliya portugalchasi tarjimalarini o‘rnatish uchun `php artisan lang:add pt_BR` buyrug‘ini bajaring. Kirishda [sozlangan muqobil nom](./configure.md#locale-aliases) qabul qilinishi mumkin, yaratilgan fayllarda esa kanonik kod ishlatiladi.

Ro‘yxatni kodda [`Locale::values()`](./locales.md#find-supported-and-installed-locales) orqali toping. Tarjima qamrovi paket va lokalga qarab farqlanadi.
