title: コミュニティプラグイン
description: Laravel-Lang コミュニティが管理する翻訳パックを紹介します。
---

| パッケージ | 翻訳対象 | 互換性 |
| --- | --- | --- |
| [forxer/generic-term-translations-for-laravel](https://github.com/forxer/generic-term-translations-for-laravel) | 一般的な用語の翻訳 | [旧版の Publisher](https://github.com/forxer/generic-term-translations-for-laravel/blob/main/composer.json) |

インストールする前に、プラグインが要求する Composer の依存関係を確認してください。プラグインの作者は[プラグイン移行ガイド](./upgrade.md#replace-legacy-plugin-registration)に従い、サービスプロバイダーへの登録方式からマニフェストの自動検出方式へ移行できます。

インストール前に、Publisher 20.x に対応し `laravel_lang.json` マニフェストを含むリリースがあることを確認してください。 [更新したパックをテストする](./plugins.md#test-a-pack-in-a-laravel-application)
