title: "Кіраванне перакладамі"
description: "Дадавайце, абнаўляйце і выдаляйце пераклады прыкладання і залежнасцей з дапамогай Mona Publisher."
---

Publisher уваходзіць у афіцыйныя пакеты перакладаў. Яго каманды Artisan запісваюць пераклады PHP і JSON у моўны каталог прыкладання, звычайна `lang/`. Файлы канкрэтных пакетаў таксама могуць запісвацца ў `lang/vendor/`.

## Даданне лакаляў {#add-locales}

Перадайце адзін ці некалькі [кодаў лакаляў](./available-locales.md), раздзяляючы іх прабеламі. Уваходныя даныя могуць змяшчаць наладжаныя аліясы, а выніковыя файлы выкарыстоўваюць кананічныя коды.

```bash
php artisan lang:add fr de_CH
```

Каманда спачатку стварае каталогі лакаляў, а затым абнаўляе **ўсе ўсталяваныя лакалі**, у тым ліку бягучую і рэзервовую лакалі прыкладання. Без аргументаў яна пытаецца, ці трэба ўсталяваць усе падтрыманыя лакалі. У аўтаматызацыі перадавайце коды яўна.

## Абнаўленне перакладаў {#update-translations}

```bash
php artisan lang:update
```

Publisher знаходзіць лакалі паводле бягучай і рэзервовай лакаляў прыкладання, файлаў і каталогаў у корані моўнага каталога і файлаў JSON у `lang/vendor/<package>/`. Адзін толькі каталог перакладаў PHP залежнасці не робіць лакаль усталяванай. Для такой лакалі выкарыстайце `lang:add`, каб стварыць адпаведны каталог прыкладання.

Пакеты перакладаў абвяшчаюць падтрыманыя пакеты, версіі і мэтавыя файлы ў [маніфестах плагінаў](./plugins.md). Publisher аб’ядноўвае агульныя слоўнікі са слоўнікамі пакета і дадае іх пераклады ў кожны мэтавы файл. Ён захоўвае староннія ключы і замяняе ключы, якія супадаюць, у тым ліку лікавыя. Калі фразы няма ў слоўніках, Publisher запісвае зыходную фразу. Захоўвайце ўласныя перавызначэнні ў асобных файлах перакладаў або [выключыце](./configure.md#skip-files-and-force-integrations) з генерацыі мэтавыя файлы, якія падтрымліваеце самастойна.

Выканайце `lang:update` пасля змены залежнасцей Composer або [налад публікацыі](./configure.md). Праверце атрыманыя адрозненні.

## Выдаленне лакаляў {#remove-locales}

```bash
php artisan lang:rm de_CH
```

Каманда выдаляе каталог і файл JSON кананічнай лакалі з кораня моўнага каталога і непасрэдна з кожнага каталога пакета `lang/vendor/<package>/`. Разам з каталогамі лакалі выдаляюцца і ўсе карыстальніцкія файлы ўнутры іх. Бягучая і рэзервовая лакалі абароненыя. Без аргументаў каманда пытаецца, ці трэба выдаліць усе неабароненыя лакалі, са стандартным адказам «не». Калі каталог лакалі з’яўляецца спасылкай, каманда выдаляе саму спасылку.

Для кожнай лакалі каманда паказвае стан `DONE`, `PROTECTED`, `INVALID`, `SKIP` або `FAILED`. Калі пасля спробы выдалення файл ці каталог застаўся, каманда паказвае яго шлях і вяртае код памылкі. Правярайце стан кожнай лакалі, бо `PROTECTED`, `INVALID` і `SKIP` могуць суправаджацца паспяховым кодам завяршэння.

## Рэзервовы пошук у JSON {#json-fallback}

Калі ключ JSON адсутнічае, `laravel-lang/json-fallback` дадае пошук у JSON рэзервовай лакалі перад пераходам да перакладаў PHP. Common уключае гэты пакет. Для асобнага ўсталявання выканайце `composer require laravel-lang/json-fallback`.

Дадайце `LaravelLang\JsonFallback\LangJsonFallbackServiceProvider::class` да сэрвіс-правайдараў прыкладання ў `bootstrap/providers.php`. Калі ў прыкладанні яўна пазначаны `Illuminate\Translation\TranslationServiceProvider`, замяніце гэты запіс правайдарам Mona. [Рэгістрацыя сэрвіс-правайдара ў Laravel](https://laravel.com/docs/13.x/providers#registering-providers)

Калі бягучая лакаль — французская, а рэзервовая — англійская, то пры пошуку ключа, якога няма ў `lang/fr.json`, цяпер можа вяртацца яго значэнне з `lang/en.json`.
