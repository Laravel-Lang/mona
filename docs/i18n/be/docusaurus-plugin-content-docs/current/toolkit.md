Toolkit — інструмент каманднага радка для абслугоўвання пакетаў перакладаў. Запускайце яго з лакальнай копіі Mona пасля ўсталявання каранёвых залежнасцей Composer. Каб публікаваць пераклады ў прыкладанні Laravel, выкарыстоўвайце [каманды Artisan](./translations.md).

```bash
composer install
php src/Toolkit/bin/toolkit list
php src/Toolkit/bin/toolkit migrate-locales --help
```

## Праверка стану перакладаў {#check-translation-status}

```bash
php src/Toolkit/bin/toolkit status src/Lang
```

Па змаўчанні каманда запісвае `locales/<locale>/_status.json` унутры праекта. Яна пералічвае запісы, захаваны пераклад якіх супадае з зыходнай фразай, і групуе іх паводле стылю. Каманда аб’ядноўвае выключэнні з `locales/_settings.json` і `locales/<locale>/_settings.json` і выдаляе пустыя справаздачы. Каб знайсці фразы, якіх у слоўніку зусім няма, параўнайце яго з зыходнымі файламі пакета.

Перадайце `--output-dir`, каб запісваць справаздачы ў файлы `<locale>.json` у асобным каталогу. За аснову для адносных шляхоў каманда бярэ бягучы працоўны каталог. Калі каталога прызначэння яшчэ няма, каманда стварае яго пры запісе першай справаздачы.

```bash
php src/Toolkit/bin/toolkit status src/Library --output-dir=workbench/status
```

Дадайце наўмысна нязменныя фразы ў `excludes` адпаведнага файла `_settings.json`.

```json
{
  "excludes": ["Laravel"]
}
```

## Кіраванне каталогамі лакаляў {#manage-locale-directories}

```bash
php src/Toolkit/bin/toolkit create-locale src/Library
php src/Toolkit/bin/toolkit delete-locale src/Library
```

`create-locale` стварае адсутныя каталогі для ўсіх кананічных [кодаў лакаляў](./available-locales.md). Новыя каталогі першапачаткова пустыя. `delete-locale` выдаляе кожны каталог непасрэдна ў `locales/`, калі яго імя адсутнічае ў гэтым спісе. Перад запускам праверце мэтавы каталог, асабліва калі ён змяшчае аліясы лакаляў або карыстальніцкія коды.

## Выдаленне састарэлых слоўнікавых запісаў {#remove-obsolete-dictionary-entries}

```bash
php src/Toolkit/bin/toolkit sync:library src
php src/Toolkit/bin/toolkit sync:package path/to/translation-pack
```

- `sync:library` збірае зыходныя фразы з пакетаў з маніфестам `laravel_lang.json` у `src/` і перазапісвае слоўнікі ў `src/Library/locales/`.
- `sync:package` чытае каталог `source/` аднаго пакета і выдаляе нявыкарыстаныя запісы ў каталогу `locales/`. Каманда выдаляе слоўнікі, якія пасля гэтага сталі пустымі.

Абедзве каманды захоўваюць наяўныя пераклады актыўных фраз і файлы, імёны якіх пачынаюцца з падкрэслівання, напрыклад `_settings.json`. Пераклады новых фраз дадавайце непасрэдна ў слоўнік.

Без аргумента `sync:library` выкарыстоўвае каталог `src/` копіі рэпазіторыя, а `sync:package` — бягучы каталог. Абедзве каманды апрацоўваюць каталогі з кананічным кодам лакалі.

## Перанос слоўнікаў папярэдніх версій {#migrate-legacy-dictionaries}

```bash
php src/Toolkit/bin/toolkit migrate-locales path/to/legacy-pack --target=path/to/new-pack/locales
```

Перадайце пакет папярэдняй версіі з каталогамі `source/` і `locales/`. Параметр `--target` задае мэтавы каталог для падкаталогаў лакаляў. Без гэтага параметра каманда аўтаматычна выкарыстоўвае `locales/` зыходнага пакета.

- Запісы з `json.json` і `php.json` пераносяцца ў `default.json`. Запісы з `json-inline.json` і `php-inline.json` пераносяцца ў `inline.json`.
- У старых JSON-слоўніках ключамі ўжо служаць зыходныя фразы. Для PHP-слоўнікаў каманда замяняе ўкладзеныя ключы зыходнымі фразамі з PHP-файлаў у `source/`.
- Запісы `_excludes.json` пераходзяць у `_settings.json` мэтавай лакалі пад ключ `excludes`.

Toolkit аб’ядноўвае запісы з мэтавымі слоўнікамі. Пры супадзенні ключоў прыярытэт мае перанесены пераклад. Калі абодва старыя фарматы даюць пераклад адной фразы, прыярытэт мае слоўнік PHP.

Каманда захоўвае файлы ў `source/` і выдаляе паспяхова перанесеныя старыя слоўнікі і файлы выключэнняў, нават калі зададзены асобны мэтавы каталог. Змены ў прыкладанні або маніфесце плагіна апісаныя ў [дапаможніку па апгрэйдзе](./upgrade.md).

## Імпарт зыходных файлаў з ZIP-архіва {#import-sources-from-a-zip-archive}

```bash
php src/Toolkit/bin/toolkit download \
  --url=https://github.com/laravel/framework/archive/refs/heads/12.x.zip \
  --directory=workbench/downloads/framework/12.x \
  --paths=src/Illuminate/Translation/lang/en \
  --only-copy
```

- `--directory` задае канчатковае месца прызначэння. `--paths` можна ўказваць некалькі разоў для каталогаў адносна кораня архіва.
- Выбраныя файлы PHP і JSON капіруюцца ў месца прызначэння з захаваннем імёнаў. Файлы PHP капіруюцца пабайтава. Аднайменныя файлы JSON аб’ядноўваюцца з прыярытэтам новых значэнняў.
- Без `--only-copy` Toolkit шукае падтрыманыя выклікі функцый перакладу з літаральнымі ключамі. Калі фразы знойдзеныя, каманда запісвае зыходны файл JSON з імем бацькоўскага каталога месца прызначэння, напрыклад `framework.json` у гэтым прыкладзе.
- Каманда патрабуе пашырэння PHP ZIP. Яна рыхтуе змены перад публікацыяй і спрабуе аднавіць папярэдняе змесціва месца прызначэння, калі публікацыя не ўдаецца.

Параметры `--url` і `--directory` абавязковыя. Каталогі з `--paths` апрацоўваюцца разам з падкаталогамі. Без `--paths` Toolkit толькі шукае ключы перакладу. Праверце знойдзеныя ключы перад даданнем у пакет.
