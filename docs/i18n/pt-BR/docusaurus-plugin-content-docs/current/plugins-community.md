| Pacote | O que oferece | Compatibilidade |
| --- | --- | --- |
| [forxer/generic-term-translations-for-laravel](https://github.com/forxer/generic-term-translations-for-laravel) | Traduções de termos genéricos | [Publisher legado](https://github.com/forxer/generic-term-translations-for-laravel/blob/main/composer.json) |

Antes de instalar, confira os requisitos do plugin no Composer. Autores de plugins podem seguir o [guia de migração de plugins](./upgrade.md#replace-legacy-plugin-registration) para mudar do registro por provedor de serviços para a descoberta por manifesto.

Antes de instalar, confira se uma versão é compatível com o Publisher 20.x e inclui o manifesto `laravel_lang.json`. [Testar o pacote atualizado](./plugins.md#test-a-pack-in-a-laravel-application)
